## 3. WDI-Kontrollpanel (alle Länder, 1990–2025)
Aufbau: `code/shared/data_prep/build_controls_wdi.R` → Output `data/processed/controls_wdi_1990_2025.csv`
Rohdaten: `data/raw/wdi/Data_all/*.csv` (je Serie durchgehend 1990–2025)

| Variable | WDI-Code | Bedeutung |
|----------|----------|-----------|
| ExtBalGDP | NE.RSB.GNFS.ZS | Leistungsbilanz, % BIP |
| XDebtGNI | DT.DOD.DECT.GN.ZS | Gesamtverschuldung, % BNE |
| GFCFGDP | NE.GDI.FTOT.ZS | Bruttoinvestitionen, % BIP |
| DebtServGNI | DT.TDS.DECT.GN.ZS | Schuldendienst, % BNE |
| ResXDebt | FI.RES.TOTL.DT.ZS | Devisenreserven, % Gesamtschuld |
| NetUSAid | DC.DAC.USAL.CD | US-Entwicklungshilfe, Nettoflüsse in US$ |
| nomGDP | NY.GDP.MKTP.CD | BIP laufende US$ |
| imf_conc | DT.NFL.IMFC.CD | Konzessionäre IMF-Nettoflüsse, US$ |
| imf_noconc | DT.NFL.IMFN.CD | Nicht-konzessionäre IMF-Nettoflüsse, US$ |
| UseIMFCredit | DT.DOD.DIMF.CD | IMF-Kreditbestand (DOD), US$ |
| ExportGDP | NE.EXP.GNFS.ZS | Exporte, % BIP (Handelsoffenheit; Placebo für H2) |
| FuelExportPct | TX.VAL.FUEL.ZS.UN | Treibstoffexporte, % Warenexporte |
| MineralExportPct | TX.VAL.MMTL.ZS.UN | Erze/Metall-Exporte, % Warenexporte |
| legelec | DPI (Database of Political Institutions) | Legislativwahljahr |

**Berechnete Variablen (build_controls_wdi.R):**
- `USaidGDP = 100 * NetUSAid / nomGDP`
- `imf_conc_gdp = 100 * imf_conc(NA→0) / nomGDP`; `imf_noconc_gdp` analog
  - DSV-Regel: NA → 0 vor der Division (DSV-Konvention, auf Nettoflüsse übertragen)
- `imf_sum_gdp = imf_conc_gdp + imf_noconc_gdp`
- `UseIMFCredGDP = 100 * UseIMFCredit(NA→0) / nomGDP`
  - Alternatives IMF-Maß (Kreditbestand statt Nettoflüsse), nur für Robustheitsspezifikationen
- `resource_dep = FuelExportPct + MineralExportPct`
  - Fehlende WDI-Werte bleiben NA (keine Null-Ersetzung)
- `legelec_l = legelec im Kalenderjahr t-1` (Konstruktion exakt nach txt2dta7.do; DPI-2023-Stand, Serie läuft nur bis 2023)

## 6. Fehlende Daten / Konzeptabweichungen
- IMF-Serien sind Nettoflüsse (DT.NFL.*), im Original Kreditbestand: Konzeptabweichung,
  Korrelation mit Originalvintage 0.65/0.35; `UseIMFCredGDP` als alternative Robustheit
- `USaidGDP`: Abweichung zum Original (dort Faktorkosten-BIP und Aid in Mio. US$);
  Median-Abweichung −14 %
- DPI läuft nur bis 2023; nicht parsbare DPI-Zeilen (Chile 2014–2017) wurden verworfen
  (außerhalb des Original-Zeitraums)
- Fehlende Kontrollwerte bleiben NA; Modelle schätzen auf vollständige Fälle, deshalb können
  Schätzjahre vom Panelzeitraum abweichen
- Länder mit fehlenden Rohstoffdaten identifizieren (NA bleibt NA, kein Ersatz durch 0)
